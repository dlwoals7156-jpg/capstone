# capstone
프로젝트명: DeepLook
(사용자 맞춤형 AI 패션 스타일링 및 실시간 매칭 시스템)

"사용자의 퍼스널 컬러와 골격 체형을 반영하여, 상황(TPO)에 맞는 실제 쇼핑 아이템을 실시간으로 큐레이션하는 차세대 패션 테크 플랫폼"

프로젝트 기획 배경
기존 검색 엔진의 문맥 이해 한계: 퍼스널 컬러가 '여름 쿨톤'인 사용자가 "여름 정장"을 검색하면, 시스템이 톤(Color)이 아닌 계절(Season)로 오해하여 시어커서나 린넨 등 얇은 여름철 소재의 의류만 추천하는 노이즈 발생함.

추상적 TPO 검색의 어려움: 사용자가 "소개팅 룩", "캠퍼스 코디"와 같은 추상적인 상황을 입력했을 때 적절한 카테고리의 상품을 찾아주지 못하는 한계가 존재함.
해결 방안: 이러한 검색 노이즈를 제거하고 사용자의 신체 스펙에 가장 어울리는 실제 상품을 안전하게 연결하고자 개발함.

핵심 구현 기술
1. 가상 터치 인터페이스 (NUI Front-end)
사용자가 화면을 직접 터치하지 않고 제스처를 통해 UI를 제어할 수 있는 3D 가상 터치 드로잉 보드 환경 제공함.
이를 통해 자신의 신체 정보(퍼스널 컬러, 골격 유형)를 직관적으로 입력할 수 있도록 구현함.

2. LLM 기반 의도 및 TPO 분석 엔진 (AI Core)
Groq의 최신 llama-3.1-8b-instant 대형 언어 모델 탑재함.
사용자가 "미팅 갈 때 입을 옷 알려줘", "데일리 룩 슬랙스" 등 자유로운 문장으로 검색하더라도 문맥 속에서 실질적인 의류 카테고리(자켓, 셔츠, 후드티 등)와 성별 의도를 완벽하게 솎아냄.

3. 하이퍼 쿼리 교정 및 커머스 맵핑 (Back-end)
FastAPI 기반의 백엔드에서 네이버 쇼핑 오픈 API와 실시간 데이터 연동함.
AI가 지어낼 수 있는 어색한 단어(예: 스웨터 자켓)를 국내 쇼핑몰 표준 카테고리(예: 니트 가디건)로 자동 치환하고, '코럴 ➔ 코랄' 같은 키워드 맞춤법 교정을 거쳐 검색 매칭률 극대화함.
[성별] + [퍼스널 컬러별 대표 황금 컬러칩] + [추출된 아이템 명사] 구조로 검색어를 강제 재조합하여 네이버 쇼핑 결과가 0개가 뜨는 현상 원천 차단함.

4. 실시간 가이드라인 생성 및 트래픽 가드
사용자의 퍼스널 컬러와 골격 특징을 반영한 맞춤형 스타일링 가이드라인 코멘트를 실시간으로 동적 조합하여 화면에 노출함.
오픈 API 호출 시 발생하는 초당 요청 제한(429 Too Many Requests)을 우회하기 위해 안정적인 트래픽 제어 슬립(Sleep) 메커니즘 적용함.

프로젝트의 기대 효과
지능형 패션 큐레이션: 추상적인 상황 언어와 복잡한 체형 스펙을 커머스 데이터와 완벽히 맵핑하여 사용자 맞춤형 원스톱 쇼핑 경험 선사함.
검색 최적화 알고리즘 정립: 자연어 모델(LLM)과 상용 오픈 API 검색 엔진 간의 쿼리 불일치 문제를 백엔드 가드 로직으로 해결함으로써, 시스템의 안정성과 검색 정확도를 대폭 향상시킴.
